# Orbit — Project Management System

A modern, frontend-only Project Management System built with React + Vite.

## Features
- Dashboard / workspace overview
- Active project cards and progress tracking
- Personal task management with completion state
- Team members and workload
- Calendar / project events
- Workspace analytics
- Settings screen
- Responsive mobile navigation
- Light / dark mode
- Mock data only — **no backend, API, authentication, or database**

## Run locally

```bash
npm install
npm run dev
```

Then open the local Vite URL shown in the terminal.

## Build

```bash
npm run build
```

## Stack
- React JS
- Vite
- Lucide React
- CSS
- Local React state / mock data
